# The mark on the download button, and where it comes from

`<name>.txt` holds the path data of a mark, one path per line, and
`<name>.box.txt` the viewBox it was drawn in. `../gen_download_buttons.py`
reads both and draws every path in the button's one ink.

`windows.txt` is Windows from the `brands` set of **Font Awesome Free 6.7.2**
(<https://fontawesome.com>). The icons are **CC BY 4.0**, which asks for
attribution and nothing else. Copyright 2024 Fonticons, Inc.

Windows is a trademark of its owner. The mark sits on the button that downloads
for that platform, unmodified apart from its colour, to name it, and nothing
here claims endorsement by or affiliation with its owner.
