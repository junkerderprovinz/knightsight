# The marks on the download buttons, and where they come from

`<name>.txt` holds the path data of a mark, one path per line, and
`<name>.box.txt` the viewBox it was drawn in. `../gen_download_buttons.py`
reads both and draws every path in the button's one ink.

`windows.txt`, `apple.txt` and `linux.txt` come from the `brands` set of
**Font Awesome Free 6.7.2** (<https://fontawesome.com>). The icons are
**CC BY 4.0**, which asks for attribution and nothing else. Copyright 2024
Fonticons, Inc.

`flatpak.txt` is Flatpak's mark, which Flatpak publishes under CC BY 3.0 at
<https://flatpak.org/press>. The path is the one from Simple Icons (the
collection itself is CC0 1.0).

Windows, Apple, Linux and Flatpak are trademarks of their owners. Each mark sits
on the button that downloads for that platform, unmodified apart from its
colour, to name it, and nothing here claims endorsement by or affiliation with
its owner.
